# МОБД — База данных маркетплейса

Учебный репозиторий по дисциплине «Математические основы баз данных» (МОБД).
Сквозной кейс — проектирование и разработка базы данных маркетплейса на PostgreSQL.

## Структура репозитория

Каждая лабораторная работа выполняется в отдельной ветке `lab_N` и содержит:

- `lab_N/schema.sql` — SQL-скрипт (или несколько скриптов), воспроизводящий результат работы;
- `lab_N/report.md` — отчёт: постановка задачи, принятые решения, тексты ключевых запросов и результаты их выполнения;
- `lab_N/*` — прочие вспомогательные материалы (диаграммы, дампы данных и т.д.).

По завершении лабораторной работы ветка объединяется с `main` через pull request.

Итоговый проект (лаба №7) размещается в ветке `final_project` и объединяет
результаты всех предыдущих работ в единую воспроизводимую схему.

## Стек

- СУБД: PostgreSQL 15+
- Язык запросов: SQL, PL/pgSQL
- Клиент: psql / pgAdmin / DBeaver

## Предметная область

Маркетплейс — площадка, объединяющая продавцов и покупателей: продавцы
размещают товары в каталоге, покупатели оформляют заказы, которые
оплачиваются и доставляются. Относительно базового кейса добавлены:
промокоды на заказ (`promo_codes`, `promo_usages`) и избранное с историей
просмотров товаров (`wishlist`, `view_history`).

Подробное описание сущностей, бизнес-правил и схемы — в отчёте `lab_1/report.md`.
