# МОБД — База данных маркетплейса

Учебный репозиторий по дисциплине «Математические основы баз данных» (МОБД).
Сквозной кейс — проектирование и разработка базы данных маркетплейса на PostgreSQL.

## Структура репозитория

Каждая лабораторная работа выполняется в отдельной ветке `lab-N`, её файлы —
в папке `lab-0N`:

- `lab-0N/*.sql` — SQL-скрипты, воспроизводящие результат работы;
- `lab-0N/REPORT.md` — отчёт: постановка задачи, принятые решения, тексты ключевых запросов и результаты их выполнения;
- `lab-0N/README.md` — перечень файлов работы и порядок запуска скриптов;
- `lab-0N/*` — прочие вспомогательные материалы (ER-диаграмма, словарь данных).

По завершении лабораторной работы ветка объединяется с `main` через pull request.

Итоговый проект (лаба №7) размещается в ветке `lab-7` и объединяет
результаты всех предыдущих работ в единую воспроизводимую схему; порядок
сборки базы с нуля — в [`lab-07/README.md`](lab-07/README.md).

## Стек

- СУБД: PostgreSQL 15+
- Язык запросов: SQL, PL/pgSQL
- Клиент: psql / pgAdmin / DBeaver

## Предметная область

Маркетплейс — площадка, объединяющая продавцов и покупателей: продавцы
размещают товары в каталоге, покупатели оформляют заказы, которые
оплачиваются и доставляются. Относительно базового кейса добавлены:
промокоды на заказ (`promo_codes`, `promo_usages`) и избранное (`wishlist`).

Подробное описание сущностей, бизнес-правил и схемы — в отчёте
[`lab-01/REPORT.md`](lab-01/REPORT.md).
