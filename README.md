# МОБД — база данных маркетплейса

Учебный репозиторий по дисциплине «Математические основы баз данных» (МОБД). Сквозной кейс — проектирование и разработка базы данных маркетплейса на PostgreSQL.

Маркетплейс объединяет продавцов и покупателей: продавцы размещают товары в каталоге, покупатели оформляют заказы, которые оплачиваются и доставляются. Относительно базового кейса добавлены промокоды на заказ (`promo_codes`, `promo_usages`) и избранное (`wishlist`). Сущности, бизнес-правила и схема описаны в [`lab-01/REPORT.md`](lab-01/REPORT.md).

## Сборка базы

```sh
psql -U postgres -f lab-01/create_database.sql
psql -U postgres -d marketplace -f lab-07/schema.sql
psql -U postgres -d marketplace -f lab-02/seed.sql
psql -U postgres -d marketplace -f lab-06/jsonb.sql
```

Скрипты создают базу `marketplace`, итоговую схему, тестовые данные и характеристики товаров в JSONB; скрипты ЛР 2–6 выполняются на собранной базе. В Windows перед запуском `psql` нужно задать `PGCLIENTENCODING=UTF8`.

## Стек

- СУБД: PostgreSQL 15+
- Язык запросов: SQL, PL/pgSQL
- Клиент: psql / pgAdmin / DBeaver
