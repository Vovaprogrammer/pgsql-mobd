# Лабораторная работа №3 — файлы

- [`queries.sql`](queries.sql) — многотабличные и аналитические запросы:
  `INNER JOIN` трёх таблиц, `LEFT JOIN` со строками без соответствий,
  группировка с агрегатными функциями, фильтрация групп через `HAVING`,
  подзапросы (скалярный, с `IN`, коррелированный с `EXISTS`), CTE с
  разбиением запроса на шаги и рекурсивный CTE для обхода дерева категорий.
- [`views.sql`](views.sql) — представления для типовых отчётов
  (`seller_revenue` — выручка продавцов, `product_rating` — рейтинг товаров)
  и обращения к ним; воспроизводим с нуля при повторном запуске.
- [`REPORT.md`](REPORT.md) — отчёт по лабораторной работе (текст каждого
  запроса и представления, его назначение и фрагмент результата).

Скрипты выполняются в базе `marketplace` после `schema.sql` (лабораторная
работа №1) и `seed.sql` (лабораторная работа №2).
