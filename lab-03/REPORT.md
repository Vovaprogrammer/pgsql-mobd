# Лабораторная работа №3. Многотабличные запросы и аналитические представления

Запросы выполняются к базе `marketplace`, созданной `schema.sql` (ЛР 1) и
наполненной `seed.sql` (ЛР 2). Тексты запросов приведены в
[`queries.sql`](queries.sql). Ниже для каждого пункта — назначение, текст

## 1. Внутреннее соединение трёх таблиц

Карточки активных товаров с названием категории и магазина вместо числовых
идентификаторов. `JOIN` (то же, что `INNER JOIN`) соединяет товар с
категорией по `category_id` и с продавцом по `seller_id`. Оба внешних ключа
объявлены `NOT NULL`, поэтому у каждого товара гарантированно есть пара в
обеих таблицах и внутреннее соединение не теряет ни одного товара: без
фильтра и `LIMIT` запрос возвращает все 3000 строк.

```sql
SELECT p.id, p.title, c.name AS category, s.store_name AS seller, p.price
FROM products AS p
JOIN categories AS c ON c.id = p.category_id
JOIN sellers    AS s ON s.id = p.seller_id
WHERE p.is_active = TRUE
ORDER BY p.id ASC
LIMIT 10;
```
```

----+-----------------------------+--------------------+----------------+----------
  1 | Ноутбук Aurora B-137        | Ноутбуки           | СпортЛайн 2    | 99500.00
  2 | Наушники Aurora C-174       | Наушники           | КнигаПлюс 3    |  3350.00
  5 | Учебник Nordis F-285        | Научная литература | Мегастор 6     |   980.00
  6 | Сборник сказок Volna G-322  | Детские книги      | ЛавкаМастера 7 |   230.00

```

## 2. Внешнее левое соединение (LEFT JOIN)

Товары вместе с их отзывами, включая товары без отзывов. `LEFT JOIN`
сохраняет все строки левой таблицы (`products`): если для товара нет
отзывов, столбцы таблицы `reviews` в результирующей строке заполняются
`NULL`. Если отзывов несколько, товар повторяется в нескольких строках —
по одной на каждый отзыв.

```sql
SELECT p.id, p.title, p.price, r.id AS review_id
FROM products AS p
LEFT JOIN reviews AS r ON r.product_id = p.id
ORDER BY p.id ASC
LIMIT 10;
```
```
 id |            title            |  price   | review_id
----+-----------------------------+----------+-----------
  1 | Ноутбук Aurora B-137        | 99500.00 |    [null]
  2 | Наушники Aurora C-174       |  3350.00 |    [null]
  3 | Телевизор Nordis D-211      | 54530.00 |    [null]
  4 | Роман Nordis E-248          |   360.00 |    [null]
  5 | Учебник Nordis F-285        |   980.00 |      1030
  6 | Сборник сказок Volna G-322  |   230.00 |    [null]
  7 | Мужская рубашка Volna H-359 |  4090.00 |       568
  7 | Мужская рубашка Volna H-359 |  4090.00 |      2197
(10 rows)
```

Пустой `review_id` — это `NULL`, подставленный `LEFT JOIN` для товаров без
отзывов (1, 2, 3, 4, 6); у товара 5 один отзыв, у товара 7 — два, поэтому
он занимает две строки. Без `LIMIT` запрос возвращает 4049 строк: 3051 пара
«товар — отзыв» плюс 998 товаров без отзывов. Внутреннее соединение
(`INNER JOIN`) вернуло бы только 3051 строку. Проверка: отзывы есть у 2002
различных товаров, 2002 + 998 = 3000 — всего товаров в каталоге.
