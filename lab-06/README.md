# Лабораторная работа №6 — файлы

- [`jsonb.sql`](jsonb.sql) — характеристики товаров в столбце JSONB `products.attributes`: добавление и заполнение по категориям, извлечение полей операторами `->` и `->>`, фильтрация по вхождению фрагмента оператором `@>`.
- [`indexes.sql`](indexes.sql) — планы выполнения `EXPLAIN ANALYZE`: два запроса из ЛР 2 и ЛР 3 до и после B-tree-индексов (`idx_products_price`, частичный `idx_orders_cancelled_user`), запрос с `@>` до и после GIN-индекса `idx_products_attributes`, сравнение времени массовой вставки в таблицу с индексами и без них.
- [`REPORT.md`](REPORT.md) — отчёт по лабораторной работе (текст каждого запроса, планы выполнения и их сравнение, обоснование добавленных индексов).

Скрипты выполняются в базе `marketplace` после `schema.sql` (лабораторная работа №1) и `seed.sql` (лабораторная работа №2) в порядке `jsonb.sql`, `indexes.sql`.
