# Лабораторная работа №2 — файлы

- [`seed.sql`](seed.sql) — наполнение всех 16 таблиц базы `marketplace`
  тестовыми данными (генерация через `generate_series`; выполняется после
  `schema.sql` из лабораторной работы №1, воспроизводим с нуля при повторном
  запуске).
- [`queries.sql`](queries.sql) — запросы на выборку и фильтрацию данных:
  `DISTINCT`, условия с `AND`/`OR`, `BETWEEN`, `IN`, `ILIKE`, `IS NULL`,
  сортировка по двум столбцам, постраничный вывод (`LIMIT`/`OFFSET`).
- [`REPORT.md`](REPORT.md) — отчёт по лабораторной работе (описание
  наполнения базы, текст каждого запроса, его назначение и фрагмент
  результата).
