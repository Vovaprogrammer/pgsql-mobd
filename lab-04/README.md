# Лабораторная работа №4 — файлы

- [`queries.sql`](queries.sql) — аналитические запросы с оконными функциями: рейтинг товаров по цене внутри категории (`ROW_NUMBER`, `RANK`, `DENSE_RANK`), три самых дорогих товара в каждой категории (нумерация в окне и фильтрация через CTE), нарастающий итог выручки по дням, доля выручки продавца в выручке категории (`SUM(...) OVER (PARTITION BY ...)`), прирост выручки к предыдущему дню (`LAG`, `LEAD`) и решение задачи пункта 4 обычной группировкой для сравнения с оконной функцией.
- [`REPORT.md`](REPORT.md) — отчёт по лабораторной работе (текст каждого запроса, его назначение и фрагмент результата).

Скрипт выполняется в базе `marketplace` после `schema.sql` (лабораторная работа №1) и `seed.sql` (лабораторная работа №2).
