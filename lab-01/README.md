# Лабораторная работа №1 — файлы

- [`create_database.sql`](create_database.sql) — создание базы данных
  `marketplace` (выполняется один раз, отдельно от схемы).
- [`schema.sql`](schema.sql) — единый DDL-скрипт: создаёт все 16 таблиц
  схемы с ключами, ограничениями и индексами; воспроизводим с нуля при
  повторном запуске.
- [`REPORT.md`](REPORT.md) — отчёт по лабораторной работе (анализ
  предметной области, бизнес-правила, ER-диаграмма, нормализация, ключи,
  иерархия).
- [`data_dictionary.md`](data_dictionary.md) — словарь данных по всем
  таблицам.
- [`ER_diagram.png`](ER_diagram.png) — физическая ER-диаграмма, полученная
  из реальной базы данных (pgAdmin ERD Tool).
