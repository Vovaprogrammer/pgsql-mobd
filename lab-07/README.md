# Лабораторная работа №7 — файлы

- [`schema.sql`](schema.sql) — итоговая схема базы данных единым DDL-скриптом: 17 таблиц с ограничениями и индексами (ЛР 1, 5, 6), функции и триггеры (ЛР 5), представления (ЛР 3); воспроизводим с нуля при повторном запуске.
- [`REPORT.md`](REPORT.md) — отчёт по итоговому проекту (состав итоговой схемы и порядок сборки базы, дополнение словаря данных, соответствие требованиям итогового проекта со ссылками на скрипты и отчёты ЛР 1–6).

База собирается с нуля скриптом `create_database.sql` (лабораторная работа №1), затем в базе `marketplace` выполняются `schema.sql`, `seed.sql` (лабораторная работа №2) и `jsonb.sql` (лабораторная работа №6). При запуске через `psql` в Windows нужно задать `PGCLIENTENCODING=UTF8`, иначе `seed.sql` завершится ошибкой кодировки.
